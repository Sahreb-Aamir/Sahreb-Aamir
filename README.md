## Selected project

**[Event Delivery Lab](https://github.com/Sahreb-Aamir/event-delivery-lab)** — A runnable Java/Kafka workbench for lost webhook acknowledgments, retries, and recovery. Its controlled experiment shows how two HTTP requests can produce two duplicate actions with a naive receiver, or one action with receiver-side idempotency.

I built this independent, AI-assisted project to make those failure boundaries observable and testable. It includes a local dashboard, synthetic failure drills, automated tests, and documented limits.
